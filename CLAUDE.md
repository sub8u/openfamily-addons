# Rules for working in this repository

This is a **public** repository. Before every commit and push:

1. **Commit identity:** commit as `sub8u` with the GitHub no-reply address
   `328836297+sub8u@users.noreply.github.com`. Never use a personal email address.
   Check with `git config user.email` before committing.
2. **No personal details:** scan the changed files, the commit message and the
   branch history for names of family members, personal email addresses, phone
   numbers, home or server addresses, IPs, private URLs, API keys, tokens, or
   anything else that identifies the owner beyond the `sub8u` username.
   Use made-up example names in documentation.
3. **No internal notes:** store-dashboard notes, review or approval history,
   submission dates, contingency plans and similar working notes stay out of
   the repository (keep them in an ignored file or outside the repo).
4. **When in doubt, ask** the owner before pushing.
